Research results

Two Axes, One Guarantee.
Every number, checkable.

Valence–arousal estimators on AffectNet with five uncertainty methods, five seeds each. Per-axis 90% intervals cover the true VA point only ~86% of the time; a single joint score restores 90% with smaller regions; and an expression absent from calibration breaks every guarantee. Below is every number, per method, per seed and per expression.

Coverage Per expression Accuracy Unseen expression Verify it yourself Per-sample predictions Raw data (JSON)

1Coverage at nominal 90%

Joint = fraction of seen test faces whose true (valence, arousal) lies in the region. Area in VA units (the square is 4). Worst = lowest joint coverage over the seven seen expressions. Shift = joint coverage on corrupted images, calibrated on clean data. Red = below nominal.

Per-axis Joint (ours) – – nominal 90%

Bars are means over seeds; whiskers ±1 std. Contempt never appears in training or calibration.

3Accuracy and probabilistic quality

CCC higher is better; RMSE, NLL, CRPS, ECE, AURC lower is better. Ensembles combine the five seeds, so they have one value.

4Can anything flag the unseen expression?

AUROC for separating contempt from seen test faces (0.5 = chance), and the share of contempt flagged at a threshold set on validation data so that ~5% of seen faces are flagged. Feature-space detectors use the network's penultimate features.

5Check it yourself

Predictions ship without AffectNet labels (licence). Put the dataset in data/raw and these commands rebuild every table from scratch.

terminal
$ git clone https://github.com/Hassan-Naeem-code/Emotion-Modelling
$ cd Emotion-Modelling && pip install numpy scipy matplotlib
$ make v2-labels PY=python3   # re-attaches labels, checking image ids
$ make v2-verify PY=python3   # recomputes the paper's tables and diffs them
$ make v2-tables PY=python3   # regenerates every table and figure
